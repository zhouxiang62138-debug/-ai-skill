# 历史报告索引

本目录保存 AI Development Team Skill 本体的开发历史报告。它们用于追溯设计、
实施、测试和评估过程，不代表当前能力状态；当前结论应优先读取上级 `docs/` 中的
协议与架构文档。

| 目录 | 文件数 | 内容 |
| --- | ---: | --- |
| `first-ask/` | 3 | First-Ask 集成设计、兼容性和迁移验证 |
| `f9-evaluation/` | 5 | 结构化返工、证据和重试治理 |
| `f10-runtime/` | 13 | 持久化 Runtime、迁移与加固 |
| `f11-f13-capabilities/` | 12 | 执行、安全和上下文能力演进 |
| `harness/` | 15 | 浏览器 Harness、质量加固和自适应门禁 |
| `production-readiness/` | 2 | 生产就绪度阶段性与最终审查 |
| `stage-reviews/` | 16 | Stage 0–8 的设计与验收记录 |

## 维护约定

- 新的阶段性报告应直接写入对应分类，不再堆放到仓库根目录。
- 历史版本保持追加式，不覆盖已有报告。
- 报告被移动或重命名时，同步更新文档、测试和生成脚本中的引用。
- 当前事实与历史报告冲突时，以 `docs/RUNTIME_CAPABILITY_STATUS.md` 和现行协议为准。
